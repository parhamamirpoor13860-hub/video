# موشن‌گرافی تبلیغاتی جشنواره تخفیف‌های شگفت‌انگیز دیجی‌کالا

پروژه تولید خودکار ویدیو موشن‌گرافی تبلیغاتی با استانداردهای رسمی برند دیجی‌کالا (Digikala Incredible Offers Commercial Motion Graphics).

## مشخصات فنی ویدیو
- **رزولوشن:** 1920 × 1080 پیکسل (Full HD - فرمت افقی ۱۶:۹)
- **نرخ فریم:** 30 فریم بر ثانیه
- **مدت زمان:** ۲۱.۵ ثانیه (۶۴۵ فریم رندر شده)
- **کدک تصویری:** H.264 (High Profile)
- **کدک صوتی:** AAC Stereo 192 kbps (موزیک الکترونیک ریتمیک + افکت‌های صوتی SFX + گویندگی فارسی هوش مصنوعی با صدای امیر)
- **تایپوگرافی:** فونت رسمی وزیرمتن (Vazirmatn Black & Bold)

## سناریو و صحنه‌های ویدیو
1. **صحنه ۱ (۰۰:۰۰ تا ۰۴:۱۲):** افتتاحیه جشنواره، لوگوی دیجی‌کالا، شمارش معکوس تخفیف و عنوان اصلی با بج پیشنهاد شگفت‌انگیز
2. **صحنه ۲ (۰۴:۱۲ تا ۰۸:۲۴):** معرفی پرچمدار گوشی‌های هوشمند بازار، کارت شیشه‌ای قیمت اولیه و قیمت با تخفیف ۴۰٪، گارانتی و ارسال سریع
3. **صحنه ۳ (۰۸:۲۴ تا ۱۲:۳۶):** معرفی ساعت هوشمند اولترا با سنسورهای سلامت و حلقه‌های فعالیت، ۴۵٪ تخفیف و نمایش قیمت استثنایی
4. **صحنه ۴ (۱۲:۳۶ تا ۱۶:۴۸):** معرفی هدفون بی‌سیم نویز کنسلینگ با افکت امواج صوتی ریتمیک، ۵۰٪ تخفیف
5. **صحنه ۵ (۱۶:۴۸ تا ۲۱:۳۰):** لوگوی رسمی بزرگ دیجی‌کالا، دکمه متحرک فراخوان به خرید (Call to Action)، آدرس digikala.com و نشان‌های دانلود اپلیکیشن

## اجرای پروژه
```bash
# نصب پکیج‌های نود
npm install

# رندر مستقیم ویدیو و ایجاد خروجی نهایی
node src/build_video.js
```

فایل نهایی در مسیر `output/digikala_motion_graphics.mp4` ذخیره می‌گردد.
